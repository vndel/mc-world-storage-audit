# Disk pressure response

1. Confirm the affected mount and identify top-level growth using read-only inspection.
2. Check server logs, backup retention jobs, crash dumps, and world-generation activity.
3. Do not delete world, region, player, or backup data during initial triage.
4. If safe headroom is threatened, pause nonessential generation or retention-expensive jobs using their documented controls.
5. Expand storage or move data only through an approved change with a verified backup.
6. Confirm server saves, backups, and monitoring recover; record the cause and prevention action.
